# CASTOR..Scientific..Calculator..Motor

![CASTOR](https://github.com/universish/CASTOR..Scientific..Calculator..Motor/blob/main/CASTOR-LOGO.png?raw=true)

A Scientific Calculator Engine written in Rust—inspired by the CASTOR constellation. This engine is the foundation of the system. You can build any calculator you want on top of this engine—for example, CASTOR functionx 82. For instance, you can replicate the features of the CASIO fx-82MS.
